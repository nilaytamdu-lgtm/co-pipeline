# Brand assets

Drop the 180DC NITW logo here as `logo.png`. Optionally also `favicon.png` for a square browser-tab icon.

If `logo.png` is missing, the app falls back to a styled text mark that uses the same brand palette — it still looks intentional.

## Files the app looks for

- `logo.png` — used in the sidebar header + as the browser tab favicon (if `favicon.png` is absent).
- `favicon.png` — used as the browser tab icon. Square, ~64×64 px works well.
